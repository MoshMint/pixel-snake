# 🐍 Pixel Snake

A retro DOS-style Snake game built with HTML, CSS and JavaScript.

## 🎮 Play Now

### [▶ PLAY PIXEL SNAKE](https://moshmint.github.io/pixel-snake/)

No installation required — just open the link and play in your browser.

## 🕹️ How to Play

Eat the apples, grow your snake, and avoid hitting the walls or yourself.

The game gets progressively faster as your score increases.

## ⌨️ Controls

- **Arrow Keys / WASD** — Move
- **Space** — Pause / Resume
- **Enter** — Start / Restart
- **Mobile** — Touch D-pad or swipe

## ✨ Features

- Retro DOS / CRT-inspired graphics
- Progressive speed levels
- Score and high-score tracking
- Keyboard controls
- Mobile touch controls
- Responsive design for desktop and smartphones
- Runs directly in the browser
- No external libraries required
